02Проблеми якості даних

Через ці проблеми Excel не можна просто «підключити» до панелі. Під час імпорту дані треба нормалізувати.

Критично

Немає ідентифікаторів студентів

У файлах є лише ПІБ. API МАУП шукає студента за student_id, nsb (номер залікової) або ipn. Без цього файли не зв'язати між собою, а однофамільців не розрізнити.

Критично

Зламані формули у звітах

На аркуші «звіти» замість відсотків стоїть #DIV/0!, а підсумки нульові. Звіти треба рахувати в системі, а не формулами в Excel.

Високо

Оцінки перетворилися на дати

Excel автоматично перетворив частину оцінок на дати (наприклад, 2026-05-04 замість «4/5»). Лише на одному аркуші журналу таких клітинок 5.

Високо

Змішані формати оцінок

Поруч стоять 5, н, н/3, есе-6, п-6, «атестовано», «атест.». Потрібен довідник типів оцінок, як /marktypes у МАУП.

Середньо

Кілька значень в одній клітинці

У розкладі викладач і дисципліна записані разом («доц. … Історія…»), а групи перелічені через кому. У контингенті статус, дата й наказ теж в одному тексті.

Середньо

Різне написання назв

«Курилін» і «Курілін», «Лазарев» і «Лазарєв», «ЦГЮ - 7/24» і «ЦГЮ 7/24», зайві пробіли в назвах груп. Потрібні довідники викладачів, груп і дисциплін.

04Рішення: одна база і два виходи

Excel-файли імпортуються в базу даних, структура якої повторює модель МАУП. Над базою працюють адмін-панель для співробітників і API у форматі МАУП для зовнішнього сервера.

Чому модель МАУП

Структуру не треба вигадувати. Вона вже перевірена реальним сервером, і інтеграція вийде «з коробки».

Чому API, а не обмін файлами

Сервер отримує актуальні дані в реальному часі: сальдо, розклад, оцінки. Ручного вивантаження немає.

Що понад МАУП

Відвідуваність, поточний журнал, гуртожиток і мобільність віддаємо через додаткові ендпоінти. Наявний сервер просто ігноруватиме їх.

07План впровадження

Етапи йдуть послідовно. Кожен дає результат, яким уже можна користуватися.

1

Ідентифікатори та довідники

Отримати номери залікових (або ІПН) для студентів. Скласти довідники груп, викладачів, дисциплін, аудиторій.

Результат: студенти однозначно зв'язуються між файлами
2

Імпорт і очищення

Скрипти імпорту трьох файлів: відновлення оцінок-дат, розбір «викладач + дисципліна», парсинг наказів, лог невідповідностей для ручної перевірки.

Результат: чиста база
3

API у форматі МАУП

Спочатку ендпоінти, які реально використовує наявний сервер. Basic-авторизація, коди помилок E-xx. Перевірка на тому самому клієнті.

Результат: сервер працює з вашими даними
4

Адмін-панель

Контингент, оплата, розклад, журнал. Потім дашборд, звіти з експортом, архів.

Результат: робота без Excel
5

Ролі та введення даних

Вхід для деканату, бухгалтерії, викладачів. Внесення оцінок, оплат і наказів прямо в панелі, Excel лише для імпорту й експорту.

Результат: єдине джерело правди

Що потрібно від університету

✅ Номери залікових книжок або ІПН студентів (найважливіше).

✅ Список ендпоінтів і полів, які використовує наявний сервер, або доступ до його коду.

✅ Повні файли: контингент усіх груп і журнали всіх груп, а не лише ПД 5/25.

✅ Навчальні плани та календарний графік, якщо потрібні /plan і /calgraph.

✅ Хостинг для бази й API та перелік ролей користувачів.
