# Адмін-панель КУІВП — аналіз і рішення

Статичний сайт з аналізом Excel-даних університету (контингент і оплата, журнал, розклад),
порівнянням з API МАУП (`api.maup.com.ua/api`) та запропонованою архітектурою адмін-панелі
з API, сумісним з форматом МАУП.

## Деплой на Netlify

1. Netlify → **Add new site → Import an existing project** → GitHub → `demo_kyivp`.
2. Build command — порожньо, Publish directory — `.` (вже задано в `netlify.toml`).
3. **Deploy**.

Локально: просто відкрийте `index.html` у браузері.

Вихідні Excel-файли містять персональні дані студентів і в репозиторій не додаються.
